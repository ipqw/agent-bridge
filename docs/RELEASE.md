Тестовая сборка Agent Bridge под Windows 10/11.

- `.msi` — установщик; ставится поверх прошлой версии, настройки и ключи сохраняются.
- `.exe` — тот же установщик в формате NSIS.

Сборка не подписана сертификатом: SmartScreen покажет «неизвестный издатель» → «Подробнее» → «Выполнить в любом случае».
