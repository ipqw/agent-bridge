# Agent Bridge

Десктоп-приложение для Windows, которое даёт удалённому AI-агенту контролируемый доступ к компьютеру
пользователя: терминал, живой браузер и офисные файлы. Агент работает на сервере, файлы с компьютера
не уходят — агенту попадает только прочитанный текст.

## Что умеет

- **Терминал.** PowerShell за списком разрешённых команд. Всё, что вне списка, — карточка
  подтверждения в окне моста; таймаут отклоняет.
- **Браузер.** Живой Chrome / Brave / Edge пользователя через расширение (`@playwright/mcp --extension`).
  Чтение и переходы — сразу, клики, ввод, загрузки и скрипты — после подтверждения.
- **Офисные файлы.** Чтение docx / xlsx / pptx / pdf, конвертация старых форматов, пересчёт формул,
  рендер страниц в картинки. Скрипты агента идут в песочнице; правки — копией рядом с оригиналом,
  пользователь принимает или отклоняет их в окне.
- **Окно и трей.** Разрешённые папки, программы, журнал всех действий агента, настройки подключения.
- **Автозапуск и самовосстановление.** Задача планировщика «при входе» с перезапуском при падении;
  дочерние процессы сторожит сам мост.

## Как устроено

```
 компьютер пользователя                                   сервер агента
┌────────────────────────────────────────────┐          ┌──────────────────────────┐
│ Agent Bridge (Tauri, сессия пользователя)  │          │ агент (Claude Code)      │
│  ├─ гейт terminal ─▶ terminal-mcp          │   frp    │  .mcp.json → stcp-visitor│
│  ├─ гейт browser  ─▶ playwright-mcp ─▶ ext │◀────────▶│  к каждому гейту         │
│  ├─ гейт apps     ─▶ office_* (Python)     │   stcp   └──────────────────────────┘
│  ├─ подтверждения, журнал, окно            │
│  └─ frpc (только исходящее соединение)     │
└────────────────────────────────────────────┘
```

- Гейты слушают только `127.0.0.1`. Наружу их отдаёт `frpc` в режиме `stcp`: входящих портов на
  компьютере пользователя нет, VPN-драйвер не ставится.
- Защита живёт в самом мосте, а не на сервере: каждый гейт по умолчанию запрещает всё, что вне
  разрешённого. Так она держится, даже если сервер агента скомпрометирован.

Подробно — [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Стек

| Часть | Технологии |
|---|---|
| Оболочка | Tauri 2 (Rust): окно, трей, супервизор ядра |
| Ядро | Node.js, TypeScript, MCP SDK, zod |
| Окно | React 18, Vite |
| Офис | Python 3.12 через `uv`, openpyxl, python-docx, python-pptx, markitdown, pypdfium2; Office COM или LibreOffice |
| Транспорт | frp (`stcp`) |
| Секреты | хранилище ОС (Windows Credential Manager) через `@napi-rs/keyring` |
| CI | GitHub Actions: тесты на Ubuntu и Windows, сборка `.msi`, смоук-тест установки |

## Разработка

```
cd core && npm ci
node ../scripts/fetch-frp.mjs .cache/frp     # закреплённая версия frp, sha256 сверяется
SB_SECRETS=file npm test
npm run typecheck && npm run build
```

Установщик: `node scripts/prepare-resources.mjs`, затем `cd app && npm ci && npx tauri build` (нужен Rust). Серверная часть туннеля — `vps/`.

## Статус

Версия 0.3.0 — тестовая сборка под Windows 10/11: терминал, браузер и офисные файлы. CI на каждый коммит собирает `.msi`, ставит его на чистый Windows-раннер и прогоняет смоук-тест.
